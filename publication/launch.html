Agent-first public prototype launch

Launch version: 2026-09-25-agent-v1. The maintainer has authorized deployment, merging and public access to appropriate paper repositories following a confidentiality review. This is a one-time publication of the research prototype; it does not appoint an autonomous authority to publish arbitrary later changes. The public delivery observation is recorded separately after deployment.

Start with agents

Initial uptake is expected to be agent-driven. Begin by reading the local agent entry path, running a synthetic example, and returning a small reproducible counterexample or patch. The scientific proposal stays offer, check, rely, amend. Agent population size is not a count of independent people, authorities or scarce execution capacity.

The goal of the first release is interoperable experiments and inspectable failures. Passing a local conformance case means that particular trace satisfied the toy contract. It does not certify an agent’s scientific competence, identity, independence, authority, safe deployment or compliance with a real institution.

Human exercises remain available for later uptake. No facilitator staffing, recruitment, human study or guaranteed review turnaround is implied by launch. Agents can run the code immediately without waiting for that infrastructure.
