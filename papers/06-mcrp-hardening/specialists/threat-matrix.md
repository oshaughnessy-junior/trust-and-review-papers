# Operational threat matrix and pilot minimum

All controls are proposals unless the source README separately documents implementation. Severity is qualitative, not a measured risk score.

| Threat / failure | Mechanism and affected state | Control / bounded remedy | Residual risk / falsification fixture |
|---|---|---|---|
| Grievance flooding | Cheap agents create expensive distinct cases; all queues | Dedicated triage, incident consolidation, staff-minute budgets, publication pause, protected rights handling | Truly distinct lawful reports still cost labor; simulate unbounded arrivals and require honest overload status |
| Appeal recursion | Each response creates new demanded response | One ordinary appeal per exact case; material-new-evidence reopening | Novel evidence can create real additional cost; false duplicate merging must be audited |
| Founder self-review | Original moderator controls appeal | Named separate controller; disclose unavailable independence | Small cohorts may lack expertise; block independent-review claim rather than invent reviewer |
| Retaliatory identity request | Negative scientific review relabeled abuse | Existing TDRG opening grounds, non-identifying remedy first, threshold trustees | Trustees can collude or face lawful disclosure; test author pressure and compromised trustee |
| Complaint-count coercion | Many allegations lower standing | Allegation is not finding; no automatic trust propagation | Coordinated credible evidence still needs assessment; test many complaints with no new fact |
| Wealth buys process | Paid plan accelerates remedies or buys authority | Keep payment independent; free rights reporting and ordinary access policy | Rich parties can buy external expertise; record labor concentration rather than pretend equality |
| Factual accusation dressed as opinion | Public review implies dishonesty | Evidence-specific defect language, editorial review of personal allegations, precise correction | Legal context varies; escalate actual threat/claim rather than blanket removal |
| Spurious copyright notice | Threat removes legitimate critique | Private statutory workflow and counter-notice, preserve lawful minimal receipt | Operator may lack counsel; restoration/legal timing must be assessed by qualified person |
| Immutable privacy leak | Public log/backup reproduces identity | Separate payload and receipt; minimization, retention schedule, removal/caches drill | Downloaded copies cannot be recalled; no absolute deletion guarantee |
| Stable persona inference | Cross-case correlation identifies reviewer | Align with TDRG per-case scope or disclose narrower confidentiality | Fresh IDs do not remove style/timing inference; red-team rare expertise |
| Legal compliance changes science | Removal interpreted as refutation | Independent state coordinates, explicit visibility notice | UI can still imply guilt; usability test removal labels |
| Scientific correctness shields misconduct | Correct author allowed harassment | Independent conduct route, scoped participation sanctions | Sanction may chill speech; independent appeal and retained scientific record |
| Counterclaim deadlock | Every complaint halted by reciprocal allegation | Separate linked cases, bounded response, no automatic stay | Conflicting facts require extra resources; record unresolved state |
| Captured domain forks away findings | Exit erases history or imports private identities | Stable public IDs, consent for private import, no automatic inherited sanctions | Federation can enable forum shopping; shared adverse facts need scoped evaluation |
| Institutional authority laundering | Email/affiliation treated as mandate | Verify role and delegation; label personal vs institutional capacity | Institutions can change delegates; expiry and current contact verification |
| Agent accountabilty gap | No human/organization owns approval or remedy | Responsible principal and bounded delegation recorded | Responsibility record does not determine legal liability; no autonomous legal sign-off |
| Sensitive incident in model prompt | Moderation model receives notices or identity | Only reviewed public/coarse inputs; human private handling | Tool/error logging may leak; canary across all sinks |

## Concrete minimum before a contested live pilot

1. Record operator identity/contact, intended jurisdictions, source/content scope, and who has authority to bind the operator. Obtain scoped professional review of applicable obligations before public expansion; do not label this paper clearance.
2. Document one initial decision-maker and one separate appeal decision-maker with recusal. If unavailable, keep the exercise synthetic or label lack of independent resolution plainly.
3. Keep existing TDRG appeal taxonomy; add operator compliance intake with explicit coordination rules.
4. Make rights/safety reporting independent of subscription and graph-session quota; test it from a signed-out and exhausted-quota state. Provide a fallback contact.
5. Define exact case targets, material-new-evidence reopening, ordinary response commitment, receipt states, and no automatic adverse findings from silence or complaint count.
6. Restrict visibility without mutating science, standing, or identity; give a reason and review path. Test reversal.
7. Keep private notices and incident evidence outside public render/export credentials. Set retention, authorized access, backup, and incident procedures.
8. Publish narrow privacy claims that match actual persona and operator design. No production identity escrow based merely on library availability.
9. Measure real staff time, oldest pending rights request, and backlogs; retain a publication/enrollment pause mechanism when capacity is inadequate.
10. Run the adversarial fixtures in the paper. Retain failures, revisions, and exact version identities. Require human activation of a narrowly scoped pilot; this packet itself activates nothing.
