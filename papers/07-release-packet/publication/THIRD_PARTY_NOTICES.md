# Third-party notices and original-material rights status

The research brief embeds subsets of the Bitstream Vera fonts supplied with
ReportLab. Their copyright, trademark and permission notice is retained in
[bitstream-vera-license.txt](notices/bitstream-vera-license.txt) and attached inside
the PDF. That existing font license is distinct from any proposed license for
this project's original text or code.

The optional renderers use ReportLab, Pillow, pypdf and Matplotlib installed in
the build environment. Their package implementations are not vendored in this
packet. The reproduction instructions distinguish those optional rendering
packages from the standard-library-only model suite. Library use does not imply
endorsement by their authors. Citations link to scholarly sources; their full
papers, third-party datasets and private review letters are not redistributed.

The new prose, code and generated figures have proposed, not adopted, project
licenses. See [the release assessment](release-assessment.md). A rights-holder
decision should preserve this notice and grant only rights actually held. The
presence of the font license does not license the rest of the packet by implication.
