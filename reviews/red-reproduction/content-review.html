Resource and information distinctions that must survive publication

  • A task decision unit is not necessarily a distinct human. Several units share one execution person. The model expressly assumes separable utility and does not solve that person’s portfolio decision or hidden common control.
  • Utility effort is not booked human time. Both honest and shallow completions spend the same review slot; private effort differences do not create free capacity. The manuscript makes this separation explicit.
  • Whole-program worst-case reservations are conservative. Shared roles can reserve twelve hours while executing ten, preserving the unconditioned quota lottery. A draw that happens to fit a smaller capacity does not justify silently rerolling or conditioning on that capacity.
  • A selected refusal consumes no audit slot and no review time in this model. That is an explicit omission of real refusal/triage labor, not an empirical finding that refusal is free. The selected, executed and unused denominators make the distinction inspectable.
  • The conditional participating-actor audit marginal needs hidden selection and independence from participation. Disclosure changes the actor’s information; all actions commit before outcomes in the main branch. The final evaluator trace is not a cryptographic concealment mechanism.
  • Distinct person labels, escrow availability, automatic auditor effort, detection quality and legitimate loss collection are stipulated. The toy transfers cannot establish independent governance, actual wealth, consent or legal enforceability.

These restrictions are already present in the funded manuscript and synthesis. They are substantive premises, not peripheral disclaimers. The claim ledger’s bounded C09–C10 formulations are consistent with them.

Remaining numerical boundary

A separate extreme-input probe used the accepted finite configuration value actor_escrow=1e308. Conversion of the aggregate exact escrow to a displayed float raises OverflowError: integer division result too large for a float. No successful overdraw or fabricated balanced report results. This is outside the small teaching values used in the retained runs, but means finite scalar validation alone is not a total runtime guarantee for every finite configuration. A future generalized API should reject unsafe output ranges or serialize exact totals. This is not a blocker for the explicitly bounded research fixtures; do not advertise arbitrary finite-range robustness.
